# CPU-only torch: sentence-transformers depends on torch, and PyPI's default
# `torch` wheel bundles full CUDA support (multiple GB of unused nvidia-*
# packages) even though this app only ever runs EMBEDDING_DEVICE=cpu.
# --extra-index-url alone does NOT reliably force pip to prefer the CPU
# build over an equally-valid PyPI CUDA build — verified empirically during
# an audit of this project: pip still resolved the CUDA wheel even with
# this line present, because both indexes satisfy the same version
# constraint and pip doesn't prefer one index over the other by default.
# This line is still correct/useful to keep (it's required infrastructure
# for the guaranteed fix), but the actual guarantee comes from installing
# torch explicitly *first* — see "CPU-only torch" in the README's
# Troubleshooting section for the one-line command (audit finding H3).
--extra-index-url https://download.pytorch.org/whl/cpu
