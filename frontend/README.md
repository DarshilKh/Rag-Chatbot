# frontend/

This is the React (Vite) + Tailwind CSS v4 frontend for **Document Chat RAG**.

For setup instructions, architecture, environment variables, testing, and everything else,
see the [root README](../README.md).

Quick reference:
```bash
npm install
npm run dev      # dev server on :5173, proxies /api to the backend on :8000
npm run build    # production build to dist/
npm run test     # Vitest suite
npm run lint     # oxlint
```
